🚀 Installatie op Homey Self-Hosted Server (SHS)

# 1. Installeer de Homey CLI (eenmalig)
npm install -g homey

# 2. Log in op je Homey account
homey login

# 3. Ga naar de app-map en installeer dependencies
cd homey-party-quiz
npm install

# 4. Start de app direct op je SHS (dev-modus met live logs)
homey app run --remote

# 5. Of installeer definitief
homey app install

# De webserver start automatisch op poort 3456:
#   http://<SHS-IP>:3456/host     → TV / hoofdscherm
#   http://<SHS-IP>:3456/play     → spelers (QR)
#   http://<SHS-IP>:3456/admin    → beheer & editor
🔒 HTTPS reverse proxy (aanbevolen voor Web Push)
Browsers staan Web Push alleen toe via HTTPS. Voeg in Nginx Proxy Manager een proxy host toe: quiz.mijn-domein.nl → http://<SHS-IP>:3456 met een Let's Encrypt-certificaat en vul de HTTPS-URL in via /settings of /admin. 
server {
    listen 443 ssl;
    server_name quiz.mijn-domein.nl;

    ssl_certificate     /etc/letsencrypt/live/quiz/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/quiz/privkey.pem;

    location / {
        proxy_pass http://192.168.1.50:3456;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
