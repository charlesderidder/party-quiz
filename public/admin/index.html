🔒 Belangrijk voor Web Push op Mobiele Browsers (HTTPS / Reverse Proxy)

Moderne mobiele browsers (iOS Safari, Android Chrome) staan Service Workers en de Web Push API (VAPID) uitsluitend toe over een beveiligde HTTPS-verbinding (of via localhost). Draai je Homey Self-Hosted Server (SHS) op Proxmox, Docker of een Synology NAS? Stel dan een Reverse Proxy in (bijv. via Nginx Proxy Manager, Caddy of Synology Application Portal met een Let's Encrypt certificaat) die verwijst naar deze Homey-app poort, en vul de HTTPS-URL hieronder in. De QR-code op /host gebruikt deze URL dan automatisch!

💡 Fallback ingebouwd: Zelfs zonder HTTPS toont Party Quiz automatisch een realtime in-app Push-notificatiebanner via Socket.io op het scherm van de speler!
